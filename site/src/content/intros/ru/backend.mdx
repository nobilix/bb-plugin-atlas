Здесь описан единственный объект, который получает серверная точка входа: 22 его неймспейса, методы `onDispose` и `onInstall`, а также внутренний `internal_DO_NOT_USE_recordPluginUse` — по порядку объявления, вместе со сводкой числовых лимитов. Префикс `experimental_` есть ровно у пяти корневых полей; у `hosts` и `sdk` его нет, хотя их основные члены его содержат.
{/* permalink: BbPluginApi */}

:::note[Несуществующие неймспейсы]
Частые ошибочные догадки: `bb.info`, `bb.ws`, `bb.threads`, `bb.dispatch`, `bb.metadata`, `bb.commands`, `bb.schedules`, `bb.services`, `bb.machines` (на самом деле `bb.experimental_machines`), `bb.ai`, `bb.browsers`, `bb.host` в единственном числе, `bb.db`, `bb.defineCli` (это свободная функция).
Веб-сокеты находятся в `bb.http.experimental_websocket`, браузеры — в `bb.sdk.experimental_desktopBrowsers`, cron — в `bb.background.schedule`, а метаданные тредов — в `bb.sdk.threads.getPluginMetadata`.
:::

## Числовые лимиты

| Лимит | Значение | Где |
|---|---|---|
| значение `kv` | 256 KB | `host-policy.ts` |
| неймспейс метаданных треда | 256 KiB | `backend-contract.ts` |
| вывод CLI (stdout + stderr) | 32 MiB, отклоняется целиком | `backend-contract.ts` |
| `requestInput` | пейлоуд 64 KiB · заголовок 160 символов · таймаут 10 мин по умолчанию, потолок 7 дней | `plugin-interaction-limits.ts` |
| подписи строк отображения | 80 символов | `host-policy.ts` |
| собственные инструкции инструмента | 4096 символов | `host-policy.ts` |
| инструкции из `configure` и `contributeInstructions` | 32 768 символов; более длинный текст обрезается | `host-policy.ts` |
| выбор `configure` | 256 id | `host-policy.ts` |
| переопределение параметров инструмента | 128 KiB | `host-policy.ts` |
| `experimental_bridgeOptions` | 64 KiB, валидируются и замораживаются при регистрации | `host-policy.ts` |
| записи переменных окружения провайдера | 32 имени, `[A-Z_][A-Z0-9_]*` | `host-policy.ts` |
| фабрика плагина | 30 с | `plugin-runtime.ts` |
| хук диспетчеризации | 10 с, fail-closed | `plugin-hook-registry.ts` |
| `search` упоминаний | 2 с, изолирован от сбоев | `backend-contract.ts` |
| `resource` окружения | 16 KiB | `backend-events.md` |
| хостовый RPC | 32 MiB на вход / 8 MiB на выход, 30 с по умолчанию, потолок 30 минут | `plugin-host-rpc.ts` |
| хостовый артефакт | 256 MiB, проверен по sha256 | `host-daemon-contract/src/protocol.ts` |
| остановка сервиса | 5 с → `degraded` | `plugin-runtime.ts` |
