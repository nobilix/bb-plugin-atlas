Здесь собраны изменения для авторов плагинов с версии 0.40.0 по 0.43.3 и описано правило стабилизации экспериментального API. Записи взяты из файла `CHANGELOG.md` закреплённого релиза и отфильтрованы: оставлено только то, что требует действий от автора плагина. В этот диапазон входят ровно пять релизов (0.43.3, 0.43.0, 0.42.0, 0.41.0, 0.40.0); версий 0.43.1 и 0.43.2 не существует, как и патч-релизов для 0.42, 0.41 и 0.40.

:::note[Правило стабилизации]
«Every public plugin API member ships with an `experimental_` prefix and an entry here… Dropping the prefix is the deliberate stabilization step: audit the entry, rename project-wide, and delete the entry in the same change».
{/* permalink: docs/api_to_audit.md */}
В реестре около 92 записей. Большинство из них следует строгой структуре: «What it does», затем «Audit before stabilizing» и нумерованный список открытых вопросов. По итогам первого аудита (2026-08-22, миграция провайдеров) стабилизированы целевые поля декларации провайдера, `maintenance` и `presentation` у инструментов, `UrlLink`/`openUrl`, `fixedTabs` и общий проп делегирования `Original`. Окна совместимости длятся один релиз, а переименованные поля регистрации отклоняются при регистрации с указанием на новое имя.
:::
