На этой странице — изменения для авторов плагинов от 0.40.0 до 0.43.3 и правило, по которому стабилизируется экспериментальный API. Записи разобраны из `CHANGELOG.md` закреплённого релиза и отфильтрованы до того, что требует действий от автора плагина. В диапазоне ровно пять релизов (0.43.3, 0.43.0, 0.42.0, 0.41.0, 0.40.0); ни 0.43.1, ни 0.43.2 нет, как нет и патч-релизов для 0.42, 0.41 и 0.40.

:::note[Правило стабилизации]
«Every public plugin API member ships with an `experimental_` prefix and an entry here… Dropping the prefix is the deliberate stabilization step: audit the entry, rename project-wide, and delete the entry in the same change».
{/* permalink: docs/api_to_audit.md */}
Реестр держит примерно 92 записи; у большинства фиксированная форма: «What it does», затем «Audit before stabilizing» — нумерованный список открытых вопросов. Первый аудит (2026-08-22, миграция провайдеров) стабилизировал целевые поля декларации провайдера, `maintenance` и `presentation` инструментов, `UrlLink`/`openUrl`, `fixedTabs` и общий проп делегирования `Original`. Окна совместимости длятся один релиз, а переименованные поля регистрации отвергаются при регистрации с указанием нового имени.
:::
