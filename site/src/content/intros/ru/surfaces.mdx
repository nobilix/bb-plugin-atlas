Здесь собраны 54 поверхности API плагинов в семи группах с той же нумерацией, что и во встроенном Plugin Guide. «Поверхность» — это продуктовая группировка из руководства: `PluginSurface { id, title, summary, bullets, apiSymbols, … }` внутри объектов `SurfaceGroup`. Номер — это индекс плюс один внутри группы, как его вычисляет `product-map.tsx` для десктопного интерфейса; у группы `headless` номеров нет.

:::note[Наглядная карта]
Те же номера прямо на интерфейсе bb (App shell · Quick palette · Home · Settings → plugin page · Plugins page) показаны [на странице /map/](/ru/map/). Ниже — табличный указатель с символами SDK и ссылками.
:::

В каждой строке указаны id поверхности, её символы в SDK, плагины из поставки bb, которые её используют, и её место в интерфейсе. Также из каждой строки можно перейти к карте и карточке соответствующего слота или неймспейса.
