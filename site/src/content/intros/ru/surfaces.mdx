API плагинов включает 46 поверхностей, разбитых на семь групп. Их нумерация такая же, как во встроенном Plugin Guide. Поверхность в этом руководстве — это продуктовая группировка: объекты `PluginSurface { id, title, summary, bullets, apiSymbols, … }` внутри `SurfaceGroup`. Номер — это индекс внутри группы плюс один (`SURFACE_NUMBERS`); у группы `headless` номеров нет.

:::note[Визуальная карта]
На странице [/map/](/ru/map/) эти же номера наложены на реальный интерфейс bb (App shell · Quick palette · Home · Settings → страница плагина · страница Plugins). Ниже — табличный указатель с символами SDK и ссылками.
:::

В каждой строке указаны id поверхности, её символы SDK, использующие её плагины из поставки bb и место в интерфейсе. Из строки можно перейти к визуальной карте и карточке слота или неймспейса, реализующего эту поверхность.
