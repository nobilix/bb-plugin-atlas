Эта страница — индекс 46 поверхностей plugin API в семи группах, пронумерованных так же, как во встроенном Plugin Guide. «Поверхность» — продуктовая группировка из этого гайда: `PluginSurface { id, title, summary, bullets, apiSymbols, … }` внутри объектов `SurfaceGroup`. Номер — это индекс плюс один внутри своей группы (`SURFACE_NUMBERS`); группа `headless` номеров не получает.

:::note[Визуальная карта]
Те же номера, нарисованные поверх настоящего интерфейса bb — App shell · Quick palette · Home · Settings → plugin page · Plugins page, — находятся на [макете зон](/ru/map/). Здесь — табличный индекс с символами SDK и ссылками.
:::

Каждая строка содержит id поверхности, её символы SDK, first-party плагины, которые её используют, и её место в UI. Каждая строка также ведёт на макет и на карточку слота или namespace'а, которая её реализует.
