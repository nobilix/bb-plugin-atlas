Every first-party plugin and example at the pinned release, with the entries it declares and its source directory. To find the plugin that shows a specific surface working, start from [Choosing a surface](/choose/), which maps goals to plugins. The Entries column lists `server` for `bb.server`, `app` for `bb.app` and `host` for `bb.host`. The Source column links the plugin's directory at the pinned commit; a plugin's id can differ from its directory name.
