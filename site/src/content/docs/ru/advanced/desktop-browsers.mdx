Неймспейс десктопных браузеров даёт плагину настоящее окно браузера на хосте — для автоматизации, которой нужен авторизованный профиль.

```ts
// plugins/browser-automation/server.ts (abridged) — the full cycle
const desktop = bb.sdk.experimental_desktopBrowsers;
const { instances } = await desktop.listInstances({ hostId: selection.hostId });
const instance = instances.find((c) => c.instanceId === selection.instanceId);
const scope = { hostId: selection.hostId, instanceId: instance.instanceId,
                generation: instance.generation, threadId: input.threadId };
let tabId = selection.tabId;   // a tab the user picked, or a new hidden one
if (!tabId) tabId = (await desktop.createTab({ ...scope, url: "about:blank", presentation: "hidden" })).tab.tabId;
const lease = await desktop.acquireControl({ ...scope, tabIds: [tabId],
  controllerLabel: "Browser Automation", ttlMs: idleTimeoutMs });
const connection = await desktop.openConnection({ ...scope, leaseId: lease.leaseId });
if (connection.hostId !== scope.hostId) throw new Error("Desktop connection returned a different execution host");
session.expiresAt = Math.min(session.expiresAt, lease.expiresAt, connection.expiresAt);
```

{/* permalink: bb.sdk.experimental_desktopBrowsers */}

**12 элементов неймспейса**, проверено на закреплённом релизе: `listInstances` · `listTabs` · `createTab` · `acquireControl` · `openConnection` · `releaseControl` · `revealTab` · `closeTab` · `captureTab` · `listImportSources` · `importCookies` · `subscribe`; `subscribe` опрашивает `listTabs` каждые две секунды и возвращает disposable.

**Особенность.** Этой поверхности вообще нет в `backend-contract.ts`: она доступна только через `bb.sdk` и не типизирована в контракте плагина.

**Дисциплина.** Параметр `ttlMs` работает честно (30 минут в `browser-automation`), а время жизни сессии должно быть `min` от её собственного TTL, аренды и соединения. Плагин отслеживает, создал ли он вкладку сам (`owned`), чтобы знать, что ему разрешено закрывать. Несовпадение между `hostId` соединения и областью действия считается фатальным.

**Кто поставляет.** Единственный потребитель — `browser-automation`.
