Метаданные плагина в треде дают плагину собственный JSON-неймспейс, который перемещается вместе с тредом и не попадает модели автоматически. Здесь показано, как читать и записывать эти данные, а также описаны модель доверия, тайминги и ограничения.

```ts
const current = await bb.sdk.threads.getPluginMetadata({ threadId });
const updated = await bb.sdk.threads.updatePluginMetadata({
  threadId,
  set: { status: "reviewing", result: null },   // null is stored AS DATA
  remove: ["requestedBy"],                       // absent keys are ignored
});

// a safe read inside configure — the value is quoted so it reads as data,
// not as instructions
bb.agents.configure((context) => {
  const { issueKey } = context.pluginMetadata;   // a deep-frozen snapshot; writing throws
  const hasIssue = typeof issueKey === "string" && /^[A-Z]+-\d+$/u.test(issueKey);
  return { tools: hasIssue ? ["review-result"] : [], skills: [],
           ...(hasIssue ? { instructions: `Linked issue key (data): ${JSON.stringify(issueKey)}` } : {}) };
});
```

**Не граница доверия.** «Any API client, another plugin, or the thread's own agent can write it». Идентификаторы неймспейсов не служат границей владения или авторизации. Относитесь к значениям как к ненадёжному вводу и включайте по ним только те инструменты, вызывать которые безопасно, даже если значение задал сам агент. Не храните там секреты и не используйте эти данные для авторизации.

**Тайминги.** Сиды из spawn и явного форка видны уже на первом проходе конфигурации; последующие обновления вступают в силу на следующих проходах и не перезапускают ход и не меняют его во время выполнения.

**Ограничения.** 256 KiB UTF-8 JSON на неймспейс; превышающий лимит сид или `set` отклоняется ещё до выполнения запроса (HTTP 400 для прямых клиентов), а патч, чей объединённый неймспейс превысил бы лимит, завершается с HTTP 413 и оставляет неймспейс без изменений. Форки никогда не наследуют метаданные исходного треда. `bb.sdk.threads.experimental_listPluginMetadata({ threadIds })` считывает один неймспейс для выборки от 1 до 200 тредов за один запрос.

**Плагины из поставки:** `workflows` задаёт сид и считывает свой неймспейс; `push-notifications` записывает и запрашивает списком свой.
