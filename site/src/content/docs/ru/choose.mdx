Поверхность — одно место, где плагин появляется или действует: страница в сайдбаре, кнопка рядом с полем ввода, инструмент в сессии агента. bb выделяет 46 поверхностей в семи группах. Чтобы выбрать, начните с того, что должен получить человек или агент, откройте first-party плагин, который уже это делает, а затем прочитайте справочную страницу поверхности с точным API. Таблицы ниже покрывают частые задачи; все 46 поверхностей собраны на странице [Поверхности](/ru/surfaces/), а [макет UI-зон](/ru/map/) показывает поверхности окна на их местах.

## Четыре вопроса

Плагин может ответить «да» на несколько из них; скаффолд из [Первого плагина](/ru/start/) отвечает «да» на первые два.

1. Человек видит это в окне bb или нажимает на это? Тогда нужна app entry. Такие поверхности входят в первые шесть групп: окно приложения, командная палитра, композер, домашняя страница, страница настроек плагина и страница плагина.
2. Агент пользуется этим во время работы? Тогда server entry даёт агенту CLI-команду вместе со skill'ом, который её объясняет, нативный инструмент или инструкции.
3. Это работает, когда никто не смотрит? Тогда server entry запускает фоновые сервисы и расписания, реагирует на события thread'ов и обслуживает HTTP-маршруты для внешних сервисов.
4. Это меняет, какой агент работает или где? Провайдеры агентов, окружений и машин — [точки расширения](/ru/advanced/); провайдеры агентов и first-party провайдеры окружений поставляются ещё и с host entry.

## В окне bb

| Чтобы добавить… | Поверхность | Какой плагин читать |
|---|---|---|
| свою страницу, которая открывается из сайдбара | [Полностраничные панели](/ru/surfaces/nav-panel/) | `tasks`, `github`; самый маленький — `plugin-api-tester` |
| вкладку в боковой панели thread'а | [Вкладки боковой панели thread'а](/ru/surfaces/thread-panel/) | `side-chat`, `github` |
| компонент внутри ответа агента | [Встраивания в сообщения](/ru/surfaces/message-directives/) | `inline-vis`, самый маленький |
| форму, которая останавливает агента, чтобы спросить человека | [Формы в thread'е](/ru/surfaces/pending-interaction/) | `ask-user-question`, `secrets` |
| действие над отдельным сообщением | [Действия с сообщениями](/ru/surfaces/message-actions/) | `side-chat` |
| просмотрщик или редактор для типа файлов | [Просмотрщики и редакторы файлов](/ru/surfaces/file-opener/) | `pdf-preview`, самый маленький; `monaco-editor` |
| элемент внизу сайдбара | [Элементы футера сайдбара](/ru/surfaces/sidebar-footer/) | `connect` |
| строки в меню + рядом с полем ввода | [Меню +](/ru/surfaces/composer-plus-menu/) | `drafts`, `scheduled-send` |
| баннер над полем ввода | [Баннеры](/ru/surfaces/composer-banners/) | `provider-retry`, `workflows` |
| результаты в меню упоминаний | [Упоминания](/ru/surfaces/mention-provider/) | `github`, `tasks` |
| команду в командной палитре | [Действия командной палитры](/ru/surfaces/command-palette-actions/) | `monaco-editor` |
| секцию на домашнем экране | [Секции домашнего экрана](/ru/surfaces/homepage-section/) | ни один first-party плагин её не использует |
| замену списка thread'ов | [Список thread'ов](/ru/surfaces/thread-list/) | `replacement-lab-alpha` вместе с `replacement-lab-beta`; ставьте оба |
| настройки, которые заполняет человек | [Поля настроек](/ru/surfaces/declarative-settings/) | `custom-instructions`, `github` |
| собственный компонент на странице настроек | [Собственная секция настроек](/ru/surfaces/settings-section/) | `keep-awake`, `memory` |
| уведомление, что плагин нужно настроить, прежде чем он сможет работать | [Статус конфигурации](/ru/surfaces/plugin-status/) | `github`, `workflows` |

Ваш UI делит окно с интерфейсом самого bb одним из четырёх способов. На additive-поверхности ваш компонент стоит рядом с компонентами bb и других плагинов. Replacement-поверхность подменяет компонент bb и откатывается к нему, если ваш упадёт. Список thread'ов — exclusive: один плагин заменяет весь список. А для host chrome, например элементов футера сайдбара, bb рисует контрол сам по данным, которые передаёт плагин. Все четыре вида определены на странице [Слоты фронтенда](/ru/frontend/).

## Для агента

| Чтобы дать агенту… | Поверхность | Какой плагин читать |
|---|---|---|
| команду, которую он запускает, и skill, который её объясняет | [Команды bb CLI](/ru/surfaces/cli/) | скаффолд; `memory`, `tasks` |
| нативный инструмент в его сессии | [Инструменты агента и skill'ы](/ru/surfaces/agent-tools/) | `ask-user-question`, `memory` |
| только инструкции, без UI | [Инструменты агента и skill'ы](/ru/surfaces/agent-tools/) | `custom-instructions`, `bb-guide` |
| гейт, который решает, можно ли отправить сообщение | [Хук диспетчеризации](/ru/surfaces/dispatch-hook/) | `concurrency-limit` |
| данные, которые идут вместе с thread'ом | [Метаданные плагина в thread'е](/ru/surfaces/thread-plugin-metadata/) | `workflows` |

## Когда никто не смотрит

| Чтобы запустить… | Поверхность | Какой плагин читать |
|---|---|---|
| долгоживущий сервис или cron-расписание | [Фоновая работа](/ru/surfaces/background/) | `automations`, `keep-awake` |
| код, когда thread стартует, завершается или падает | [События жизненного цикла thread'а](/ru/surfaces/thread-events/) | `push-notifications`, `provider-retry` |
| webhook-эндпоинт с проверкой подписи | [HTTP, WebSocket, RPC и realtime](/ru/surfaces/wire/) | `slack-bot`, пример без зависимостей |
| собственную базу SQLite с миграциями | [Хранилище](/ru/surfaces/storage/) | `memory`, `github`, `tasks` |
| код, который создаёт thread'ы и проекты | [SDK самого bb](/ru/surfaces/bb-sdk/) | `automations`, `tasks` |

## Где и как работает агент

| Чтобы предоставить… | Поверхность | Какой плагин читать |
|---|---|---|
| нового агента в выборе модели | [Провайдеры агентов](/ru/surfaces/provider-picker/) | `provider-acp`, `provider-pi`; самый маленький — пример `echo-provider` |
| место, где живёт workspace thread'а | [Провайдеры окружений](/ru/surfaces/environment-providers/) | `environment-git-worktree`, `environment-project-checkout` |
| машину, на которой работают thread'ы | [Провайдеры машин](/ru/surfaces/machine-providers/) | `environment-modal-sandbox` |
| собственный код на машине агента | [Host-воркеры](/ru/surfaces/host-workers/) | `keep-awake`, `environment-personal-workspace` |

Самый полный first-party референс — `tasks`. [Каталог](/ru/plugins/) перечисляет все first-party плагины с их точками входа и размером.
