Поверхность — это конкретное место, где плагин появляется или работает: страница в боковой панели, кнопка рядом с полем ввода, инструмент в сессии агента. bb определяет 46 поверхностей в семи группах. Чтобы выбрать подходящую, отталкивайтесь от того, что должен увидеть человек или агент. Откройте плагин из поставки bb, который уже это делает, и прочитайте страницу справочника по этой поверхности, чтобы узнать точный API. Таблицы ниже охватывают частые задачи; все 46 поверхностей собраны в разделе [Поверхности](/ru/surfaces/), а [макет зон](/ru/map/) показывает поверхности окна на своих местах.

## Четыре вопроса

Плагин может ответить «да» на несколько вопросов сразу; шаблон плагина из раздела [Ваш первый плагин](/ru/start/) отвечает на первые два.

1. Человек видит этот элемент или кликает по нему в окне bb? Тогда вам нужна клиентская точка входа. Поверхности находятся в первых шести группах: окно приложения, палитра команд, композер, домашняя страница, страница настроек плагина и страница плагина.
2. Агент использует это в работе? Тогда серверная точка входа даёт агенту команду CLI и скилл, который ей обучает, нативный инструмент или инструкции.
3. Это работает без участия человека? Тогда серверная точка входа запускает фоновые сервисы и расписания, реагирует на события треда и обслуживает HTTP-маршруты для внешних сервисов.
4. Это меняет то, какой агент работает или где он запускается? Провайдеры агента, окружения и машины — это [точки расширения](/ru/advanced/); провайдеры агента, а также провайдеры окружения из поставки bb включают хостовую точку входа.

## В окне bb

| Чтобы добавить… | Поверхность | Какой плагин читать |
|---|---|---|
| свою страницу, которая открывается из боковой панели | [Панели на всю страницу](/ru/surfaces/nav-panel/) | `tasks`, `github`; самый маленький — `plugin-api-tester` |
| вкладку в панели рядом с тредом | [Вкладки правой панели треда](/ru/surfaces/thread-panel/) | `side-chat`, `github` |
| компонент внутри ответа агента | [Встраиваемые компоненты в сообщениях](/ru/surfaces/message-directives/) | `inline-vis`, самый маленький |
| форму, которая ставит агента на паузу, чтобы задать вопрос человеку | [Формы в треде](/ru/surfaces/pending-interaction/) | `ask-user-question`, `secrets` |
| действие для конкретного сообщения | [Действия с сообщением](/ru/surfaces/message-actions/) | `side-chat` |
| просмотрщик или редактор для определённого типа файлов | [Просмотрщики и редакторы файлов](/ru/surfaces/file-opener/) | `pdf-preview`, самый маленький; `monaco-editor` |
| элемент внизу боковой панели | [Элементы подвала боковой панели](/ru/surfaces/sidebar-footer/) | `connect` |
| строки в меню + рядом с полем ввода | [Меню +](/ru/surfaces/composer-plus-menu/) | `drafts`, `scheduled-send` |
| баннер над полем ввода | [Баннеры](/ru/surfaces/composer-banners/) | `provider-retry`, `workflows` |
| результаты в меню упоминаний | [Упоминания](/ru/surfaces/mention-provider/) | `github`, `tasks` |
| команду в палитру команд | [Действия палитры команд](/ru/surfaces/command-palette-actions/) | `monaco-editor` |
| секцию на домашнем экране | [Секции главного экрана](/ru/surfaces/homepage-section/) | плагины из поставки bb это не используют |
| замену списку тредов | [Список тредов](/ru/surfaces/thread-list/) | `replacement-lab-alpha` вместе с `replacement-lab-beta`; установите оба |
| настройки, которые заполняет человек | [Поля настроек](/ru/surfaces/declarative-settings/) | `custom-instructions`, `github` |
| свой компонент на странице настроек | [Собственная секция настроек](/ru/surfaces/settings-section/) | `keep-awake`, `memory` |
| уведомление, что плагин нужно настроить перед запуском | [Статус конфигурации](/ru/surfaces/plugin-status/) | `github`, `workflows` |

Ваш UI делит окно с интерфейсом bb одним из четырёх способов. На аддитивной поверхности ваш компонент располагается рядом с компонентами bb и других плагинов. Замещающая поверхность подменяет компонент bb и откатывается к нему, если ваш компонент падает. Список тредов эксклюзивен: один плагин заменяет весь список. А для хостового хрома, например элементов внизу боковой панели, bb рисует контрол на основе данных, которые передаёт плагин. Эти четыре вида описаны в разделе [Слоты фронтенда](/ru/frontend/).

## Для агента

| Чтобы дать агенту… | Поверхность | Какой плагин читать |
|---|---|---|
| команду для выполнения и скилл, который ей обучает | [Команды CLI bb](/ru/surfaces/cli/) | шаблон плагина; `memory`, `tasks` |
| нативный инструмент в его сессии | [Инструменты и скиллы агента](/ru/surfaces/agent-tools/) | `ask-user-question`, `memory` |
| только инструкции, без UI | [Инструменты и скиллы агента](/ru/surfaces/agent-tools/) | `custom-instructions`, `bb-guide` |
| шлюз, который решает, можно ли отправить сообщение | [Хук диспетчеризации](/ru/surfaces/dispatch-hook/) | `concurrency-limit` |
| данные, которые передаются вместе с тредом | [Метаданные плагина в треде](/ru/surfaces/thread-plugin-metadata/) | `workflows` |

## Без участия человека

| Чтобы запустить… | Поверхность | Какой плагин читать |
|---|---|---|
| долгоживущий сервис или расписание cron | [Фоновая работа](/ru/surfaces/background/) | `automations`, `keep-awake` |
| код при старте, завершении или падении треда | [События жизненного цикла треда](/ru/surfaces/thread-events/) | `push-notifications`, `provider-retry` |
| эндпоинт вебхука с проверкой подписи | [HTTP, WebSocket, RPC и realtime](/ru/surfaces/wire/) | `slack-bot`, пример без зависимостей |
| свою базу SQLite с миграциями | [Хранилище](/ru/surfaces/storage/) | `memory`, `github`, `tasks` |
| код, который создаёт треды и проекты | [SDK bb](/ru/surfaces/bb-sdk/) | `automations`, `tasks` |

## Где и как работает агент

| Чтобы предоставить… | Поверхность | Какой плагин читать |
|---|---|---|
| нового агента в селекторе моделей | [Провайдеры агента](/ru/surfaces/provider-picker/) | `provider-acp`, `provider-pi`; самый маленький — пример `echo-provider` |
| место, где находится рабочий каталог треда | [Провайдеры окружения](/ru/surfaces/environment-providers/) | `environment-git-worktree`, `environment-project-checkout` |
| машину для выполнения тредов | [Провайдеры машин](/ru/surfaces/machine-providers/) | `environment-modal-sandbox` |
| свой код на машине агента | [Хост-воркеры](/ru/surfaces/host-workers/) | `keep-awake`, `environment-personal-workspace` |

Самый полный пример из поставки bb — `tasks`. В [каталоге](/ru/plugins/) перечислены все плагины из поставки bb, их точки входа и размер.
