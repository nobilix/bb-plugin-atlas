Этот сайт объясняет, как работают плагины bb, и документирует каждую поверхность, которую может занять плагин. **bb** ([getbb.app](https://getbb.app)) — открытая «agentic IDE that builds itself». Она работает как Node-сервер с базой SQLite в роли источника правды, демон хоста на каждой машине-исполнителе, клиентское приложение (веб, Electron, мобильное) и CLI `bb`. Практически всё видимое в интерфейсе и почти все действия агента реализованы как плагины поверх единого публичного SDK. Этому SDK и посвящён сайт.

## Маршрут для чтения

Читайте первые четыре страницы по порядку. Каждая следующая опирается на предыдущую — от устройства bb в целом до кода конкретного плагина:

1. [Как работает bb](/ru/concepts/): три процесса и объекты, которыми bb в них управляет.
2. [Как устроен плагин](/ru/architecture/): три точки входа, их взаимодействие, где хранится состояние и что происходит при перезагрузке.
3. [Первый плагин](/ru/start/): создайте шаблон плагина, установите его, опробуйте в трёх местах и измените код.
4. [Выбор поверхности](/ru/choose/): от идеи к подходящей поверхности и плагину из поставки bb, который стоит изучить.

Дальше держите справочник под рукой при разработке. Он сгенерирован по закреплённому релизу bb, поэтому любая страница либо совпадает с кодом релиза, либо ломает сборку:

- **[Поверхности](/ru/surfaces/)**: каждое место, где плагин может отображаться или действовать.
- **[Клиентские слоты](/ru/frontend/)**: точки регистрации, через которые клиентская точка входа подключается к поверхностям.
- **[Серверные неймспейсы](/ru/backend/)**: элементы API, которые передаются серверной точке входа.
- **[Макет зон интерфейса](/ru/map/)**: те же поверхности с номерами прямо на окне приложения.

## Как читать справочник

Каждый символ на этом сайте отмечен одним из двух индикаторов статуса, и только у них есть цветная точка:

- `stable`, изумрудный: имя не содержит префикса, а ломающие изменения потребуют смены мажорной версии.
- `experimental_`, кобальтовый: префикс входит в само имя, а в файле `docs/api_to_audit.md` перечислено, что нужно проверить перед тем, как его уберут.

Карточка, члены которой частично стабильны, а частично имеют префикс, отмечена обоими индикаторами. Обычная плашка без точки — это просто метка (например, имя члена, тип слота или роль поверхности), которая ничего не сообщает о стабильности.

Каждое имя, путь и число ведёт на GitHub к закреплённому коммиту, с точностью до строки, если она известна. Ссылки генерируются из `data/symbols.json`, а не проставляются вручную. Идентификаторы, пути, команды и строки интерфейса bb приводятся в точности так, как они написаны в репозитории. Если факт не удалось подтвердить при анализе кода, в тексте прямо сказано **не проверено** вместо догадок.

## Кнопки брифа для агента: что попадает в буфер обмена

В каждой карточке поверхности, слота, неймспейса и точки расширения есть три действия. Каждое копирует готовый контекст для агента, который будет писать плагин.

| Кнопка | Что попадает в буфер обмена | Куда вставлять |
|---|---|---|
| **Brief for agent** | Бриф в формате Markdown: описание возможности, в какой точке входа она находится, точный вызов регистрации, тип пропсов, тип слота, стабильность, символы SDK с путями и номерами строк, какой плагин из поставки почитать, правила, на которых спотыкаются авторы, и критерии приёмки | любой терминальный агент (Claude Code, Codex, Cursor): вставляйте первым сообщением задачи |
| **as a bb mention** | Формат, совпадающий с выводом встроенного Plugin Guide: `text/plain` с текстом `Build a plugin that uses @<Title>` и `text/html` с атрибутом `data-prompt-mention`. В композере bb этот фрагмент превращается в настоящее упоминание поверхности | композер bb (при включённом плагине `plugin-api-docs`; иначе вставится обычный текст) |
| **add to set** | Собирает поверхности в набор; панель в правом нижнем углу копирует **один** бриф сразу для нескольких возможностей: общий шаблон плагина, архитектура, по блоку на каждую возможность, объединённые правила и чеклист | плагин, решающий несколько задач сразу: один запрос к агенту вместо трёх |

Набор сохраняется при переходах по страницам и перезагрузке (`localStorage`). Ссылки «open in bb», включая ссылку на встроенный Plugin Guide, ведут на запущенный на этой машине bb (`http://localhost:38886`).
